      Wiring guide ▾

      Power flows from the battery into the motor driver. The driver makes its own 5 V supply that can run the brain board, or the brain can take battery power on VIN.

      Every part must share one ground (GND), or signals have nothing to measure against.

      Sensors run on 5 V. Never send the 9 V battery straight into them.

      Driver side A runs the left motor and side B the right. Match + to + and − to −.

      Pins the robot’s code expects

      D3Left motor speed, to driver AIN
      D5Right motor speed, to driver BIN
      D7Distance sensor TRIG
      D8Distance sensor ECHO
      A0Left line sensor (L)
      A1Right line sensor (R)

      How blocks run

      Blocks run one at a time from top to bottom, starting under “when Run is pressed.” The block the robot is doing right now lights up.

      Blocks that say “for … seconds” finish their move before the next block starts. Blocks that say “start,” like start driving, leave the motors on and move straight to the next block.

      Loops repeat about 20 times every second, just like the control loop on a real robot.
